## 보물찾기게임
게임 맵에 `0`은 빈 공간, `1`은 보물이 있는 곳입니다.
플레이어가 행과 열을 입력하면 해당 위치를 확인합니다.
보물을 찾으면 `"보물 발견!"`을 출력하세요.

```python
map = [
    [0, 0, 0],
    [0, 0, 1],
    [0, 0, 0]
]  

a = 
``` 


**출력**
```python

행을 입력하세요: 1
열을 입력하세요: 1
보물이 없습니다

행을 입력하세요: 1
열을 입력하세요: 2
보물 발견!
```
