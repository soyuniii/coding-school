### 치즈 먹기 게임

쥐가 3×3 게임판에서 움직이면서 치즈를 먹는 게임을 만들어 봅시다.
게임판에서 `1`은 치즈가 있는 곳이고, `0`은 치즈가 없는 곳입니다.

쥐는 다음과 같이 움직입니다.

- `w` : 위로 이동
- `s` : 아래로 이동
- `a` : 왼쪽으로 이동
- `d` : 오른쪽으로 이동

치즈가 있는 칸으로 이동하면 치즈를 먹고 점수가 1점 올라갑니다.

총 10번까지 움직일 수 있고, 치즈를 3개 모두 먹으면 게임이 바로 끝납니다.

다음 코드를 완성해 봅시다.

```python

map = [
    [0, 1, 0],
    [0, 0, 1],
    [1, 0, 0]
]

row = 0
col = 0
score = 0
count = 0

while count < 10:
    print()
    print("현재 위치:", row, col)
    print("현재 점수:", score)

    move = input("이동하세요 (w/a/s/d): ")

    
    if move == "w":
        # 위로 이동

    elif move == "s":
        # 아래로 이동
    
    elif move == "a":
        # 왼쪽으로 이동
    
    elif move == "d":
        # 오른쪽으로 이동


    if 현재 위치에 치즈가 있다면:
        print("치즈를 먹었습니다!")


    if 치즈 3개 모두 먹었는지 확인:
        print("치즈 3개를 모두 먹었습니다!")
        print("게임 성공!")
        __________

print("게임 종료!")
print("최종 점수:", score)

```
